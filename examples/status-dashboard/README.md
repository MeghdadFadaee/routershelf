# Legacy LAN status dashboard

This independent BusyBox/Netcat example reports basic router status. It has no HTTPS or authentication and is restricted to a trusted LAN. It was removed from the original router.

Read the [standalone tutorial](../../docs/examples/status-dashboard.md) before using it. Copy `config.example.sh` to a private `config.sh` in this directory. Do not expose this service with RouterShelf's public gateway rules.
